# SecurePro Selector

A responsive, static quotation-request website for seven security and solar services.

## Run it

Open `index.html` with the VS Code **Live Server** extension, or open it directly in a browser. No build step is required.

## Customise

- Change the recipient in `js/wizard.js` (`WHATSAPP_NUMBER`).
- Edit the question flows and price guidance in `js/services.js`.
- Replace the logo text and contact details in the HTML files.

Each wizard saves progress in the browser while the page remains open. Submitting opens WhatsApp with a formatted quote request; it does not calculate a binding price.
